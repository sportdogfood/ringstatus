This is retained baseline exception behavior, not a new deletion regression, but the candidate only isolates retireCleanup failures and does not fulfill the stated general unaffected-work behavior for publication failure. Smallest correction: preserve the publication error as overall Error while completing independent authorized actions and accounting for the already-issued local request.

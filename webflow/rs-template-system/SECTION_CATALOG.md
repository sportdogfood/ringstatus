# Section Catalog

Stable section names let runners build pages from explicit parts.

| ID | Alias | Type | Notes |
|---|---|---|---|
| `topnav` | `nav` | navigation | Fixed/sticky top nav, mega menu trigger, drawer trigger. Requires `rs-scripts.js`. |
| `mega-menu` | `mega` | navigation | Full-width nav dropdown. Keep paired with `topnav`. |
| `right-drawer` | `drawer` | navigation | Right drawer and scrim. Requires `body.is-nav-locked` behavior in `rs-scripts.js`. |
| `section-01-hero-split` | `s01` | standard | Split hero section. |
| `section-02-split-reverse` | `s02` | standard | Reverse split section. |
| `section-03-centered-intro` | `s03` | standard | Centered no-split copy section. |
| `section-04-wide-content` | `s04` | standard | Wide no-split section. |
| `section-05-wildcard-about` | `s05` | wildcard sticky | Sticky panel with scrolling proof cards. |
| `section-06-wildcard-blog` | `s06` | wildcard sticky | Sticky blog/archive pattern. |
| `section-07-wildcard-products` | `s07` | wildcard sticky | Sticky product-card pattern. |
| `section-08-basic-layout` | `s08` | standard | Basic layout examples. |
| `section-09-full-list` | `s09` | list | Expanding list. Requires `[data-list-limit]` behavior in `rs-scripts.js`. |
| `section-10-pricing` | `s10` | cards | Pricing/card comparison section. |
| `footer` | `footer` | footer | Full-height footer section. |

## Copy Rule

When a prompt asks for section IDs, copy those exact sections from `master_ks`, keep their wrapper order, and edit only page-specific content unless the user asks for a structural change.

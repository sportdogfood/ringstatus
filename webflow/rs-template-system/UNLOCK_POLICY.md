# Unlock Policy

`master_ks` and future `master_app` are gold sources.

## Normal Work

- Do not edit gold files.
- Copy the needed source files into a starter output folder.
- Validate the copied files before changing text, section order, or page-specific classes.

## Unlock Work

Editing gold requires an explicit user instruction:

```txt
UNLOCK MASTER_KS
```

or:

```txt
UNLOCK MASTER_APP
```

If the user does not provide an unlock instruction, stop before changing gold and create or modify a copied starter output instead.
